# صيّاد الصور (ImageGrabber)

تطبيق أندرويد (Kotlin + Compose) للبحث في Pexels وتنزيل الصور جماعيًا.

## إنشاء APK من GitHub Actions
1. ارفع المشروع إلى مستودع GitHub (الفرع `main`).
2. تبويب **Actions** ← **Build APK** ← **Run workflow** (يعمل تلقائيًا أيضًا عند كل push).
3. بعد النجاح نزّل `apks` من قسم Artifacts وفك الضغط. ثبّت `app-release.apk` (الإصدار الجاهز للاستخدام) أو `app-debug.apk`.
تُشغَّل الاختبارات تلقائيًا قبل البناء؛ إن فشلت يُرفع تقريرها باسم `test-reports`.
(التوقيع بمفتاح تصحيح ثابت `app/debug.keystore` فيمكن تحديث التطبيق فوق النسخة القديمة.)

## المصادر ولوحة التحكم
المصادر: Pexels، Pixabay، Unsplash، Flickr (بمفاتيح)، وOpenverse وWikimedia Commons (بلا مفتاح). الافتراضي «كل المصادر (تناوب)».
الإعدادات ← **لوحة التحكم (المشرف)**: بريد المشرف + رمز يُنشأ عند أول دخول. تضيف فيها أكثر من مفتاح لكل موقع ويتناوب التطبيق بينها تلقائيًا ويوقف المفتاح الذي بلغ حده مؤقتًا. المفاتيح تُحفظ على الهاتف فقط.

## (قديم) ضبط مفتاح المصدر
اختر المصدر من الإعدادات. Pexels أوقف إصدار مفاتيح جديدة مؤقتًا، فالافتراضي Pixabay (مفتاحه من pixabay.com/api/docs).
المتغيرات: `PIXABAY_API_KEY` و`PEXELS_API_KEY`.

- **داخل التطبيق (الأسلم):** تبويب الإعدادات ← الصق المفتاح ← حفظ. لا يدخل المستودع ولا الـ APK.
- **GitHub Secret:** Settings ← Secrets and variables ← Actions ← New secret باسم `PEXELS_API_KEY`
  (يُدمج في APK الخاص بك؛ لا تشارك هذا الـ APK مع أحد).
- **محليًا:** `PEXELS_API_KEY=...` في `local.properties` (مستبعد من Git).
احصل على مفتاح مجاني من https://www.pexels.com/api/
